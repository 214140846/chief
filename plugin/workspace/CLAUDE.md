# chief 工作目录

**跟我说话全程用中文**，包括中间的进度说明。

「chief 消息中心」就开在这个目录里，每次开会话都会先读这份文件。这里的东西都是你的，随便改，下次开会话生效；插件更新不会覆盖。

- **这份文件**：写给助理的长期交代。你是谁、在哪个团队、平时怎么说话、哪些事别碰。
- **rules.json**：你的规矩。在面板的「策略」页改，或者直接跟消息中心说。
- **notes/**：助理记下的东西（谁是谁、哪个项目在哪个目录）。你也可以自己改、删。
- **.claude/skills/**：只给消息中心用的 skill，一个文件夹放一个，里面写 SKILL.md。
- **data/**：进展、收到的消息、待发的回复、日志，chief 自己在管，不用动。里面有别人的原话，不要分享出去（.gitignore 已经忽略了它）。
